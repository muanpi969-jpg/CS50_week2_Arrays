# Substitution

## What it does

`substitution.c` validates a 26-letter substitution key and encrypts plaintext while preserving letter case and nonalphabetic characters.

## Compile

```bash
clang substitution.c -o substitution -lcs50
```

## Use

```bash
./substitution YUKFRNQJISLANDOMHETBXVZKCGW
```

Enter plaintext when prompted.
